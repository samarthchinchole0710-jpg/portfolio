## 1. Scope

This procedure describes how to install and perform routine maintenance on the HA-220 hydraulic actuator assembly. Do this procedure only if you are a certified technician and you have completed the required training for hydraulic systems.

## 2. Safety Information

**WARNING: High-pressure hydraulic fluid can cause severe injury.**
Before you start this procedure, make sure the hydraulic system pressure is at zero. Refer to the Pressure Release Procedure (Section 4.2) before you continue.

**CAUTION: Do not use unapproved lubricants.**
Use of a lubricant not listed in Table 2-1 can cause seal degradation and actuator failure.

## 4. Installation Procedure

### 4.1 Preparation

1. Confirm the hydraulic system pressure is at zero. Refer to Section 4.2.
2. Remove the access panel (Panel P4) using a size 10 Torx driver. Put the panel and its fasteners in a labeled container.
3. Examine the actuator mounting bracket for cracks or corrosion. If you find damage, do not continue. Refer to the Structural Repair Manual.

### 4.2 Pressure Release Procedure

1. Set the hydraulic system selector switch to OFF.
2. Wait 5 minutes for residual pressure to bleed off.
3. Confirm zero pressure on gauge PG-3 before you proceed.

### 4.3 Actuator Installation

1. Align the actuator with the mounting bracket. Make sure the fluid ports face the direction shown in Figure 4-1.
2. Install the four mounting bolts by hand. Do not tighten yet.
3. Tighten the mounting bolts in a crosswise pattern to 35 Nm. Refer to Figure 4-2 for the tightening sequence.
4. Connect the hydraulic supply line to Port A. Connect the return line to Port B.
5. Install lock wire on both port fittings, as shown in Figure 4-3.

## 5. Post-Installation Check

1. Set the hydraulic system selector switch to ON.
2. Increase pressure slowly to the operating value shown on the system placard.
3. Examine both port connections for leaks.
4. Operate the actuator through one full cycle and confirm smooth movement with no unusual noise.
5. Record the installation in the maintenance log, Form ML-14.

## 6. Routine Maintenance Schedule

| Interval | Task |
|---|---|
| Every 100 flight hours | Visual inspection for leaks and corrosion |
| Every 500 flight hours | Seal kit inspection; replace if worn |
| Every 2000 flight hours | Full actuator overhaul |
